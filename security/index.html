Security

Built to stay in control.

LUMO treats authority, execution, credentials, resources, and recovery as explicit system boundaries.

Local-first

Local intelligence is preferred where supported. Cloud providers are explicit choices.

Signed releases

Release metadata is Ed25519-signed and artifacts are SHA-256 verified before update promotion.

Root authority

Root controls platform telemetry and safety workflows while execution belongs to bounded Nodes and Worlds.

Recovery

Emergency stop, durable state, backup/restore, and rollback are first-class recovery paths.
