REQUIREMENTS

Know what LUMO needs before you install it.

Requirements are published only for platforms that have passed release validation.

macOS

Public Mac requirements will be finalized with the first notarized release. LUMO uses local intelligence when available and adapts its resource use to the machine.

Windows and Linux

Platform support is not advertised as production-ready until native packaging, permissions, computer control, local-model behavior, updates, and clean-machine validation have passed.
